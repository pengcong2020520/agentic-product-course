## 2. 产品终态（一句话）

学完以后，读者亲手做出了一个部署在腾讯云上的 AI 陪伴：在终端和飞书里能文字、能语音，记得用户、人设稳定；每次发布都过评测门禁，线上坏样本会变成新的评测用例。

## 4. 评测体系（贯穿全书）

- **一套评测仓** `evals/`：s02 建立，之后每章加用例；每章 README 固定一节"本章新增的评测"。
- **四个维度**：
  1. 对话质量：共情、自然、不说教，参考 ESConv 支持策略；
  2. 人设一致；
  3. 记忆：记得对、不张冠李戴、删了就真忘；
  4. 体验与成本：延迟、首字时间、识别错误率、每次对话成本。
- **三类评分器**：代码规则、模型评判（G-Eval rubric，用人工标注校准）、人工抽检。每次判定有三种结果：通过、不通过、没能判定。
- **三层**：单轮用例 → 模拟用户多轮对话 → 线上（Langfuse 在线评判，坏样本回流）。
- **门禁**：能力评测逐步"毕业"成回归评测；PR 必须过回归，按 pass^k 计。
