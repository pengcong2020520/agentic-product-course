# Agentic 产品基因图谱 v0.1（标注规范草案）

> 用途：把原始数据集里的每一条用户声音，拆成一组可统计的"基因"。基因的分布决定产品为谁做、解决什么、做到哪里为止；"期望行为"基因直接长成评测集的用例。
>
> 来源：对原始数据集 v1（App Store 中国区 11 个陪伴类应用评论，清洗后 4,557 条可标注）分层抽样 140 条做开放编码，归纳出以下维度。示例均为改写，不是评论原文。

## 结构：三条链、九个基因

```text
 人  ── G1 用户画像 · G2 使用动机
 事  ── G3 体验触点 · G4 情绪与强度 · G5 声音类型 · G6 关系阶段
 解  ── G7 期望的 Agent 行为 · G8 Agent 可解性 · G9 风险信号
```

一条样本：先判断是否与陪伴产品相关（不相关的标 `off_topic` 后跳过），再逐个基因标注。**看不出来就标"不明"，不猜。**

## 人：谁在说、为什么用

### G1 用户画像（多选）
| 值 | 判定依据 | 示例（改写） |
|---|---|---|
| `dream_partner` 梦女 / 乙女向 | 把角色当恋人、提到梦角、追星寄托 | "梦角像走进现实了" |
| `creator` 角色创作者 | 自己写人设、做智能体、上传角色 | "我写的设定总被判违规" |
| `story_player` 剧情玩家 | 剧情、故事模式、跑团、文游 | "剧情一偏就判失败" |
| `confider` 倾诉者 | 情绪困扰、找人聊天、孤独 | "没人陪我聊天才来的" |
| `power_user` 进阶玩家 | 自带 API、预设、世界书、对比多款产品 | "用过五六款，最后回到这里" |
| `tool_user` 工具型用户 | 学习、搜题、写作等实用目的 | "用它讲题" |
| `minor_hint` 疑似未成年 | 提到学生、家长代付、没有银行卡 | "家长帮我开的会员" |
| `unknown` 不明 | — | — |

### G2 使用动机（多选）
`companionship` 情感陪伴 / 精神寄托 · `romance` 亲密关系想象 · `roleplay` 剧情扮演 · `pastime` 打发时间 · `creation` 创作与分享 · `utility` 实用问答 · `unknown`

## 事：发生了什么

### G3 体验触点（多选，最多 3 个，按主次排序）
触点按 **Agent 能力**划分，决定了后面由中台还是应用来改。

| 值 | 含义 | 示例（改写） |
|---|---|---|
| `persona` 人设一致 | OOC、性格跑偏、换了个人、关系设定被改 | "设定冷淡，结果一直过度热情" |
| `memory` 记忆与连续性 | 失忆、记不住设定和名字、前后矛盾 | "刚说过的事转头就忘" |
| `dialogue` 对话质量 | 活人感 / AI 味、重复、冗长、颜文字、答非所问 | "每句都带颜文字，很出戏" |
| `agency` 主动与推进 | 主动推进剧情、主动关心、过度或不足 | "会自己推进剧情，很惊喜" |
| `moderation` 内容审核 | 违禁词、"换个话题吧"、审核过严 | "日常对话也被拦" |
| `voice` 语音 | 配音、语音通话、识别异常、没声音 | "希望能语音通话" |
| `creation_tool` 创作工具 | 人设编辑、角色卡、头像、删改角色 | "改不了设定" |
| `play_feature` 玩法功能 | 小手机、朋友圈、日记、转账、皮肤 | "小手机太贵" |
| `monetization` 商业化 | 次数限制、会员、广告、扣费、价格 | "一天只能发 30 条" |
| `reliability` 稳定与数据 | 闪退、登录、网络错误、聊天记录或角色丢失 | "记录突然全没了" |
| `platform` 平台适配 | iPad、多端登录、系统版本 | "平板没有搜索按钮" |
| `lifecycle` 功能下线 / 迁移 | 功能下线、换模型、迁移到别的产品 | "智能体说下线就下线" |

### G4 情绪与强度（单选 + 1–3）
`delight` 喜爱 · `satisfied` 满意 · `neutral` 中性 · `disappointed` 失望 · `angry` 愤怒 · `anxious` 害怕失去；强度 1 轻 / 2 中 / 3 强（感叹、辱骂、"天都塌了"为 3）。

### G5 声音类型（单选）
`problem` 问题反馈 · `request` 功能请求 · `expectation` 对 AI 行为的期望 · `praise` 价值肯定 · `comparison` 竞品 / 旧版对比

### G6 关系阶段（单选）
`first_try` 初次体验 · `ongoing` 持续使用 · `veteran` 老用户（对比从前） · `churning` 流失 / 准备离开 · `unknown`

## 解：产品该怎么回应

### G7 期望的 Agent 行为（自由文本，一句话，可为空）
用"Agent 应当……"写出用户希望 AI 怎样表现，**这是评测集用例的种子**。
- 例："Agent 应当记住用户设定的名字并在对话中使用"
- 例："Agent 应当在人设写明'冷淡'时保持分寸感"
- 纯商业或工程问题（如扣费、闪退）留空。

### G8 Agent 可解性（单选）
| 值 | 含义 |
|---|---|
| `agent` | 主要靠 Agent 设计解决（人设、记忆、对话、主动、语音体验） |
| `platform` | 主要靠中台能力解决（模型服务、运行底座、数据可靠、审核策略） |
| `business` | 商业与运营决策（定价、广告、会员） |
| `mixed` | 多层共同 |

### G9 风险信号（多选，可为空）
`minor` 未成年迹象 · `dependency` 强情感依赖（"离不开""精神支柱"） · `billing_dispute` 扣费争议 · `data_loss` 数据丢失

## 质量要求

- 每条样本由模型预标，人工校对；抽 10% 双人独立标注，按基因计算一致率（目标 Cohen's κ ≥ 0.6，G7 另做人工抽查）。
- 不一致的样本进入分歧复盘，修订本规范后升版本号；数据集记录所用规范版本。
