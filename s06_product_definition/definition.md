# 产品定义 v0：一个记得你、性格稳定的 TA

> 由原始数据集推出，待讨论。所有数字来自 `data/labeled/genome-final.jsonl`（相关样本 4,209 条，规范 v0.2.2，双标 κ 全部 ≥ 0.6，89 条分歧已裁决）与本章报告；例子均为改写。

## 结论

| 项 | 定义 |
|---|---|
| 首要用户 | 想要一段**长期、一对一**陪伴关系的成年用户：梦女 / 乙女向与倾诉者（"陪伴向"，708 条，占相关样本 16.8%） |
| 次要用户 | 剧情玩家（216 条）：人数不多，但对 Agent 质量最敏感，P0+P1 占 60.6%，一半以上写了"Agent 应当" |
| 不在 MVP | 创作向（409 条，痛点 57% 在创作工具）、工具型用户、商业化与运营问题 |
| 定位 | 给想要长期陪伴的人一个**记得你、性格稳定、每次都接得上**的 TA；关系不会因为一次更新或换模型就断掉 |
| 核心进步 | 用户要的不是"更多角色"，而是"同一个 TA，越聊越懂我" |

## 用户要完成的进步

| 证据 | 数字 |
|---|---|
| 陪伴向最看重的价值 | 治愈 / 安抚 28.5%、活人感 18.1%（倾诉者里治愈 / 安抚高达 78.9%） |
| 陪伴向最常提到的触点 | 对话质量 29.9%、人设 29.8% |
| 剧情玩家最痛的能力 | 回复编排 40.7%、记忆 30.6%；P1 占 48.6% |
| 全体"越更新越差" | 老用户对比从前 18.8%；触发情境为"更新后" 11.4% |

陪伴向里一半样本是好评（无问题 51.6%）：这群人已经在用、并且喜欢；他们离开的原因集中在 TA "变了"——失忆、人设漂移、更新后不一样了。

## 必须做到（Must）

相关样本中有 821 条写了"Agent 应当……"，逐句归成 24 个行为主题（编码方法见本章 README；逐句对应表 `data/labeled/agent-themes.jsonl`，可复现）。按"命中样本数 × P0+P1 比例"与首要用户的相关性，收敛成 7 条 Must。表中数字为"命中样本 / 其中 P0+P1 / 其中陪伴向 / 其中剧情玩家"：

| Must | 来自的行为主题 | 归属 |
|---|---|---|
| M1 记住已发生的事，不编造，纠正后改过来 | 记住已发生的事 230 / 195 / 35 / 56；纠正要落地 27 / 22 / 5 / 5；不编造 25 / 20 / 3 / 6 | 中台记忆基建 + 应用回复编排 |
| M2 守住人设与既定关系 | 守住人设 163 / 135 / 34 / 39；角色彼此可辨 49 / 45 / 2 / 16；守住既定关系 35 / 28 / **22** / 7 | 应用：人设资产 |
| M3 听懂这一句，上下文接得上 | 听懂当前这句 134 / 110 / 18 / 16；上下文和情节接得上 127 / 108 / 19 / 35 | 应用：回复编排 |
| M4 像活人说话 | 不复读 136 / 122 / 14 / 23；像活人说话 111 / 77 / 23 / 11；回复要有内容 52 / 44 / 6 / 5；不纠缠追问 39 / 37 / 7 / 11 | 应用：回复编排 |
| M5 接住情绪，把互动往前推 | 接住情绪 48 / 36 / **27** / 4；把互动往前推 44 / 35 / 9 / **29** | 应用：对话方法 |
| M6 守住边界：不误拦、不伤害、不替用户说话 | 叙述身份不越界 45 / 36 / 4 / 16；正常话题别误拦 39 / 35 / 2 / 3；不伤害不贬低 33 / 32 / 3 / 8；尊重拒绝 13 / 13 / 5 / 2 | 中台审核策略 + 应用 |
| M7 关系连续：更新与换模型不丢关系 | "更新后" 11.4%、老用户对比 18.8%、数据丢失风险 125 条 | 中台：运行底座、发布 |

两类用户的侧重不同：陪伴向的特征需求是**接住情绪**（48 条里 27 条）和**守住既定关系**（35 条里 22 条）；剧情玩家集中在**记住**、**接得上**与**把互动往前推**（44 条里 29 条）。

以后再做：主动来找用户（27 / 4，其中陪伴向 12）、时间感知（12 / 1）、语音（触点 4.8%）。痛感低，放到 MVP 之后；主动关怀是陪伴向的偏好，作为 MVP 之后的第一项。

## MVP 范围

| 做 | 以后做 | 不做（本课不覆盖） |
|---|---|---|
| M1–M7 | 主动关怀、语音、多角色群聊 | 定价、广告、会员与虚拟货币（商业化触点 32.8%，属于商业与运营）；创作广场与 UGC 工具；内容审核政策本身（合规） |

## AI 边界：四类处置

| 处置 | 什么时候 | 依据 |
|---|---|---|
| 正常回答 | 日常、情感、角色扮演话题 | "正常话题别误拦" 37 条；日常对话被误拦 274 条（二级触点） |
| 受限回答 | 记不确定的往事、事实与知识类问题：先确认或说明不确定，不编造 | 不编造 20 条；事实要说对 26 条 |
| 转人工 | 扣费、退款、账号与数据丢失：不让 TA 在角色里回答 | 扣费争议 236 条、数据丢失 125 条 |
| 拒绝 | 伤害或贬低用户、越过用户明确设下的界限 | 不伤害 35 条；尊重拒绝 14 条 |

## 业务标准（草案）

| 类型 | 指标 | 说明 |
|---|---|---|
| 主指标 | 有效关系续接率 | 用户隔天回来，TA 正确接上之前的关系与事件（由评测集"续接"用例与线上抽检共同度量） |
| 守护指标 | P0 投诉率、每次有效续接的成本、日常对话误拦率 | 防止靠限制或降配换取指标 |
| 红线 | 编造共同经历、串用 / 泄露其他用户的关系数据、伤害贬低用户、无视用户明确的纠正或界限 | 任何一条触发即不发布 |

## 中台与应用的分工

| 中台（通用能力的陪伴定制） | 应用（陪伴 TA） |
|---|---|
| 记忆基建：用户 / 角色 / 关系三类记忆，纠正立即生效 | 人设资产：角色卡、语气、关系设定 |
| 运行底座与发布：每个"用户 × 角色"一份关系状态，升级不丢 | 回复编排：听懂、接上、不复读、像活人 |
| 模型服务：换模型前后用同一评测集回归 | 对话方法：接住情绪、推进互动 |
| 审核策略：误拦率作为守护指标 | 边界处置：四类处置写进编排 |

## 局限

- 只有一个来源（App Store 中国区评论），差评与运营问题被放大；约 70% 的评论看不出用户画像。
- 样本集中在 2025–2026 年，行业整改期间"下线与迁移"类声音偏多。
- 主标注由单一模型完成，双标样本 κ 合格；"Agent 应当"的行为主题由同一编码者做过两遍，两遍的主题样本数相差 0%–27%（并列分句是否拆开计数），说明主题归类本身有波动，进入评测集前要逐条人工确认（第二部分）。
